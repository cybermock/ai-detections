# Live validation — AI-RBA content pack v1.1.0

**Author:** Trevor Mock, Hurricane Labs LLC. Security Operations Architect

Date: 2026-10-09/10. Environments: 4 production Splunk Enterprise Security tenants (Splunk Cloud 10.4–10.5, ES 8.5–8.7), referred to as Tenant A–D. Every test was read-only: searches were rendered with `saved_searches/tools/render_live_spl.py` (repo macros expanded, repo lookups inlined) and run as ordinary search jobs. Nothing was deployed and no configuration was written.

Shared defects found live and fixed: ES `identity_lookup_expanded` has no `department` field (the old risk multiplier was a FATAL error); the CIM DLP data model is `DLP`, not `Data_Loss_Prevention`; DNS answers carry trailing dots (`chatgpt.com.`); SSE/CASB proxies put app names, not domains, in `Web.site`; several tenants' Web data model holds inbound (load balancer, WAF, IIS) logs rather than user egress.

## Performance notes

Searches still running when the 300 s test cap expired on the two largest tenants (about 1.8 B Web and 1.1 B DNS events/day): `hdsi_ai_dns_queries_to_ai_domains`, `hdsi_ai_first_seen_provider_for_user` and `hdsi_ai_usage_volume_anomaly` on Tenant A; `hdsi_ai_new_provider_adoption_velocity` and `hdsi_ai_usage_volume_anomaly` on Tenant B. All are daily, off-hours rules over 1-30 day lookbacks. Expect multi-minute runtimes at that scale: the DNS rule pre-filters `DNS.query` with leading-wildcard terms (needed for trailing dots and prefixed names) and computes a per-source distinct-name guard over the whole day. On very large tenants, check scheduler run times after enablement and consider narrowing the pre-filter macros or lengthening `schedule_window`.

## Deploy-time tuning that matters most

- **Sanction your approved AI providers first** (`ai_sanctioned_entities.csv`, including the org-wide `*|<provider>` key). Without it, the web-access rule produced ~2,400 user risk events/day on the largest tenant; with three mainstream providers sanctioned, ~110.
- **Map ES identity `bunit` values** to `ai_department_sensitivity.csv` so `ai_risk_multiplier` can raise scores for sensitive groups (tenants with hierarchical bunit paths need a mapping).
- **Microsoft 365 Copilot ships disabled (opt-in)**: from late 2026 the Microsoft 365 home page redirects to `copilot.cloud.microsoft`, which would otherwise flag ordinary Office use.
- **Adhoc packages** need data or setup most tenants lack (a business-hours clock, browser paste telemetry); enable them only after confirming it exists. **Incubating** detections are not released; test them read-only where their data exists (see `saved_searches/incubating/README.md`).

```

```
